- **Go oracle:** local bundled toolchain is `go1.27.1 darwin/arm64`, not yet an adopted pin. Pin distribution/compiler hashes, GOOS/GOARCH, tags, CGO, GOENV/GOFLAGS, workspace/module roots and dependency snapshots identically across target/tips/merge/subsets. Use `GOTOOLCHAIN=local`, `GOWORK=off` for single-module fixtures and explicit read-only module mode; toolchain auto-selection can otherwise download/switch versions ([Go toolchains](https://go.dev/doc/toolchain)).
- Downloads are not offline: prefetch and hash dependencies during setup, then label with isolated caches and `GOPROXY=off`/`GOSUMDB=off`; missing cached modules are environment exclusions. `-mod=readonly` alone does not disable downloads, and default vendoring can change resolution ([modules](https://go.dev/ref/mod)). Keep `go build ./...` as the Q1 semantic oracle and vet as a separately captured channel; `build && vet` conflates them and loses vet output after build failure.
- Five plausible dependency-light candidates have no `require` entries in their inspected go.mod: [uuid](https://raw.githubusercontent.com/google/uuid/master/go.mod), [pflag](https://raw.githubusercontent.com/spf13/pflag/master/go.mod), [httprouter](https://raw.githubusercontent.com/julienschmidt/httprouter/master/go.mod), [chi](https://raw.githubusercontent.com/go-chi/chi/master/go.mod), [cors](https://raw.githubusercontent.com/rs/cors/master/go.mod).

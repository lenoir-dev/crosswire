# T21a differential baseline

Owner: Deneb. Scope: PLAN-v0.5 Amendment P1, T21a only. No S16/S17/S18 work or project Git mutations.

The baseline directory is a local artifact, gitignored and backed up privately, not committed: the original fixture tar headers include the host OS user/group names. Its manifest SHA-256 `98fb360c5a07e8a2cec9dfcc359b6ca92d276a8a8e177f3d07f431fc269c692c` remains the immutable pin; no baseline file was rewritten. `--artifacts PATH` (already supported, now documented in CLI help) allows an external baseline location, with the same default `docs/validation/t21-baseline`. Future captures zero uid/gid/mtime and clear uname/gname and overriding PAX owner/time fields. These harness edits change its hash: replay the original pin with its archived comparator/collector revision; do not reseal or weaken the drift check to use the updated recorder with old expectations.

The immutable baseline is complete: **334 fixtures, 43,726 raw records**, manifest SHA-256 `98fb360c5a07e8a2cec9dfcc359b6ca92d276a8a8e177f3d07f431fc269c692c`. **Self-check PASS:** v0.4.0 and archived HEAD `2cb3a06` each matched all 43,726 frozen records, with zero mismatches; source and toolchain stability checks passed. [t21a-baseline-audit.json](t21a-baseline-audit.json) verifies unique baseline record IDs and all raw streams: 19,717 exit-0, 17,843 exit-1, 6,166 exit-2 records, zero internal-error outputs. These are process statuses, not semantic quality metrics. There are 289 fixtures with nonempty release cache seeds and 45 without usable seed entries.

The release tag is `v0.4.0`: annotated tag object `b97f209f364580fa1cfcf8a93827ac8e95fb5763`, peeled commit `9bcce0fe75100712b1b34b91b48afa891019fdbe`. [t21a-provenance.json](t21a-provenance.json) records both object IDs, the tag-object byte hash and the identical source-tree IDs. The baseline inputs come from a `git archive` export of that tag. A second archive of HEAD `2cb3a06cf2084292d9732fc44c03891de636d866` supplies the unchanged-source self-check candidate: Altair began editing the shared worktree during harness construction, so the self-check does not describe those uncommitted refactor edits.

The comparator is [benchmarks/t21_equality.py](../../benchmarks/t21_equality.py); its release-suite collector is [benchmarks/t21_capture.py](../../benchmarks/t21_capture.py). The collector runs the release's own pytest suite in a separate process and archives repository states at analysis/CLI entry and teardown. All **449 release tests passed** (setup, call and teardown, no skips). The raw harvest has 577 snapshots; input-only deduplication retains **334 distinct fixtures and 782 original invocations**. The original harvest remains separately hash-bound; no output expectations exist during this input step. Tests without repositories remain explicit in the inventory; they are release assertions, not invented CLI fixtures.

Every archived fixture additionally runs pairwise and combined in text/JSON/GitHub/SARIF, and plan in text/JSON. Each distinct observed repository/root/target/base/working-directory scope receives its own matrix, including alternate bare, shallow and unborn repositories; literal input path spelling is preserved. Forward and reverse branch orders are retained separately; original invocations also retain the suite's explicit permutations, schema requests and error paths. Cache variants are disabled, cold, warm, release-preseeded and malformed. Warmup outputs are checked too. Preseeded entries come exclusively from v0.4.0 and are restored identically for each source; malformed variants retain those real keys and replace bytes with invalid JSON or invalid JSON shapes. Fixtures that cannot generate summaries have empty seeds; they do not establish cache-hit behavior.

Each CLI execution is a fresh process with the same interpreter, locale, hash seed, Git configuration, fixture path and arguments. A bootstrap verifies that `crosswire` came from the selected source tree and executes its real `__main__` module; cwd, editable installs and user site packages cannot select another implementation. Outputs are captured as bytes. Base64 in gzip JSONL preserves the exact stdout/stderr streams, including carriage returns, missing final newlines and non-UTF-8 bytes. Exit status is a separate integer. No output is parsed, sorted, projected, scrubbed or re-recorded during comparison. Earlier completed tag recordings used its equivalent `cli.main` entry; the final baseline replay checks every one through `__main__` without changing expectations.

The immutable recording under `t21-baseline/` contains `manifest.json` and its SHA-256, the hashed fixture/test inventory, compressed fixture archives, release cache snapshots and raw release outputs. The manifest binds source files, tag commit, Python/Git binaries and versions, collector/comparator hashes, release test-file hashes and each recording. Ordinary runs replay **both** baseline and candidate against the frozen bytes; baseline drift therefore also fails. Record mode explicitly requires a new artifact directory and refuses replacement. `--resume-recording` can continue an unfinished recording only from checksummed completed outputs, without rewriting those files; it refuses a finalized manifest or changed completed bytes. Recorder revisions are archived and associated with their output files. Do not refresh expectations to make a candidate pass.

To create source exports without changing checkout, index or refs:

```sh
mkdir /tmp/crosswire-t21a-release /tmp/crosswire-t21a-head
git archive v0.4.0 | tar -x -C /tmp/crosswire-t21a-release
git archive 2cb3a06cf2084292d9732fc44c03891de636d866 | tar -x -C /tmp/crosswire-t21a-head
```

The recorded artifact uses a fixed disposable fixture namespace, `/private/tmp/crosswire-t21a-fixtures` on the measurement host. Replays restore only direct children of that dedicated namespace; their contents are disposable. Run independent comparators serially: they share these fixed paths. This comparator holds a nonblocking advisory lock at `/private/tmp/crosswire-t21a-fixtures.lock`; an independent comparator should honor the same lock. Within one run, only fixtures in different parent directories execute concurrently. The gate is pinned to the recorded interpreter/Git binaries and platform paths, with a recording-context guard across recovery. Checkouts may live elsewhere, but fixture paths cannot be rewritten without changing the expected raw repro/error bytes.

```sh
.venv/bin/python benchmarks/t21_equality.py \
  --baseline /tmp/crosswire-t21a-release --candidate /tmp/crosswire-t21a-head
.venv/bin/python benchmarks/t21_equality.py \
  --baseline /tmp/crosswire-t21a-release --candidate . \
  --output docs/validation/t21-candidate.json
```

`--fixture ID` is a diagnostic subset and reports `partial`, never a full gate pass. Timeouts, source changes during execution, fixture changes, missing/mismatched artifacts and protected repository-state mutations fail the run. Virtual unreferenced Git objects and tool cache writes are allowed; HEAD, index, refs, config, worktree bytes/modes, dirty files and symlinks are checked independently for both implementations.

`tests/test_t21_equality.py`: **15 passed**. Synthetic negative controls cover changed raw stdout/stderr/exit, CRLF, EOF/newline changes, non-UTF-8, JSON key order, selected-source imports, exact cache restoration, archive tampering, path escape and repository-state mutation. An end-to-end synthetic recording/replay keeps the baseline identical, changes candidate stdout, detects both candidate records, and confirms the frozen output file is untouched. Recovery rejects changed completed expectations; entry-point regressions and concurrent namespace use are detected. Subset/permutation invocations remain intact while the complete branch set gets its scope's expanded matrix; early completed fixtures retain their additional subset matrices unchanged. These tests do not read either holdout.

Completed measurements are in [t21-self-check.json](t21-self-check.json): **87,452 executions**, 43,726 per source, across all 334 fixtures. Per-source counts comprise 782 original invocations and 42,944 expanded-matrix executions (including seeds/warmups). Each mode/format has 4,224 records, except combined/JSON with 4,928 including seed executions. Cache counts per source: cold 8,526; disabled 7,040; warm 14,080 including warmups; preseeded 7,040; malformed 7,040. Raw actual stdout/stderr/exit records are preserved in `t21-self-check.outputs.jsonl.gz`, SHA-256 `300adfe47bba2d3aa090623fb108b1fec216fed19cca2ca0aa51fbd14234242e`. The final resumed invocation took 7,645.22 seconds, including its remaining recording work and full replay; this is not isolated replay timing or a performance benchmark. [t21a-seal-check.json](t21a-seal-check.json) confirms all 29 public sealed files unchanged, without opening private paths.

Limitations: this proves the comparator's unchanged-source self-check against archived HEAD, not equality of Altair's refactor; Polaris is running that separate gate. Coverage is the frozen release-fixture corpus, not all possible Python/Git inputs. Tests without repository fixtures remain release assertions; direct internal API assertions are not a candidate API compatibility proof. Empty cache seeds do not prove cache-hit behavior. The run pins one recorded interpreter/Git environment and fixed fixture paths; it does not replace the required Python 3.11/3.14 suites, platform checks, or S14 performance gates. Vega should independently decode the recorded raw streams and compare them using her own comparator; this harness is not her independent proof. No S16/S17/S18 measurement or project Git mutation was performed.

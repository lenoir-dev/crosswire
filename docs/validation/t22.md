### Attribution: code changes versus run variability

The paired unchanged combined/plan medians span 0.974–1.031× pre-T22, median 0.999×. The paired pre-T22 run itself breaches 19 of these 34 cell time ceilings. This directly rules out attributing all initial time breaches to T22. It does not prove that contention caused each outlier, and no timing gate is waived on that basis.

For the eight initially failing RSS cells, final4 exceeds the paired pre-T22 peak by 0.484–0.766 MiB. These repeated resident increases are evidence of a fixed T22 footprint cost, consistent with the fixed module/startup footprint of the new machinery, rather than CPU contention.

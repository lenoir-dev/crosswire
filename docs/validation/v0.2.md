Prefilter substantially reduces rule calls, but this pre-A2 fixture shows no meaningful
wall-time improvement: Git subprocess work dominates. Warm cache was **not
being reused** in that revision, explaining its lack of improvement. The focused regression
`test_warm_cache_reuses_summary_without_diffing` caught calls to public
`git.changed_files` despite valid on-disk entries (PLAN-v0.2 §12.3). Source inspection
shows the cache's round-trip validity comparison treats JSON lists and dataclass
tuples as unequal; entries containing signatures/call shapes are recomputed.
These are pre-A2 measurements, not claimed cache speedups for the corrected implementation.

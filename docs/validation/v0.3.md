  Pinned pre-change archives plus data-only guard tests prove that distinction.

  distinct ordered non-empty prefixes**, across 3-, 4-, and 5-branch fixtures. Checks

## Django screening and coverage limitations

A larger, separately recorded cohort has 25 Django refactoring/removal heads,
including #22162 removing the module-level `django.utils.version.PYPY` constant.
[Selection](django-v03-prs.json) and [pairwise output](django-v03-pairwise.json)
record 300 pairs, 23.231 s, 254 CW005, and zero non-CW005 predictions against
target `102c3c327d4974a58883b47a68f8d85da0be3648`.

The predeclared full checker was Pyright **1.1.407**, Python **3.14.8**, basic mode,
the complete `django` and `tests` trees, pinned [configuration](django-v03-pyrightconfig.json).
Dependencies in the isolated oracle environment were asgiref 3.13.0, sqlparse 0.6.1,
nodeenv 1.12.0 and typing-extensions 4.16.0. No syntax-only surrogate was used.

The target alone failed: **28,353 errors**, 97 warnings over 2,920 files in 13.631 s.
The [oracle record](django-v03-oracle-target.json) retains diagnostic identifiers,
sample diagnostics and the full raw-output hash/path. Missing optional dependencies,
dynamic framework typing and negative test fixtures make this full-checker target
ineligible. We did not weaken diagnostics until it passed or label its failures
as cross-branch conflicts. No parent/merge labels were collected after this failed gate.

Pre-T13 combined attempts were stopped without reports after **10:20** (25 heads)
and **6:46** (a five-head focus); [attempt records](django-v03-limits.json) preserve
the commands and reasons. Partial output is never counted as a clean result.
A post-T13 five-head focus retry also timed out at **180.362 s** with no report;
[raw attempt](django-v03-focus-combined.json) records the limit and source hashes
and unchanged HEAD/index/worktree/refs. This attempt is not counted as a clean result.
This is a documented large-repository scaling/coverage limitation, not measured recall.

## T13 performance

[scale-v0.3.json](scale-v0.3.json) records the 30-branch / 435-pair synthetic experiment.
All four cache/prefilter modes assert identical findings and unchanged repository
state. The current contract's reference is 4.5 s warm; ≥30% improvement means ≤3.15 s.
The isolated warm median is **0.636 s** (about **85.9% lower**), cold 0.952 s and
no-cache 0.918 s. Warm runs reuse all summaries. No pytest or field jobs competed
with this run. Peak worker RSS is about 26.4 MB (Darwin reports bytes); the artifact
records Apple M5, 16 GiB RAM, macOS 27.2, Git 2.50.1 and Python 3.11.17.
This meets the current T13 target; it is not the full v0.4 5/10/30 × repository-size
× mode matrix and does not override the measured Django timeout limitation.
